# Design Analysis: Selfvoy

> Analysis generated with the `anydesign` skill. Date: 2026-10-16. Emphasis: design system

## Source

Не захват чужого сайта, а **новая дизайн-система**, выведенная из разбора
конкурентов (`RESEARCH.md`): Blockit, Howie, Granola, Poke, Lindy, Reclaim/Motion.
Прямой захват их CSS был закрыт сетевой политикой; наблюдения о них — ⚠️.
Все токены ниже — решения Selfvoy ✅, контраст проверен `check_contrast.py`.
Эталонная реализация — `preview/` (интерактивный пример всех экранов).

## TL;DR

Selfvoy выглядит как хорошо оформленная деловая переписка, а не как ИИ-продукт:
бумага, чернила, сериф и ровно два цвета — ваш и собеседника. Главный момент
бренда — **«Точка встречи»**: синяя и коралловая точки сближаются по раундам и
пересекаются, когда договорённость найдена. Если в макете нет двух сторон, синий
работает один — как цвет вашего посланника и единственный цвет действия.

## 1. Visual identity

### 1.1 Surface description

- **Personality:** спокойный, дипломатичный, тёплый, точный, немного редакционный ✅
- **Mood:** утро с чистым столом: бумага `{colors.paper}` (#F3EFE6), чёрные чернила, одна синяя ручка ✅
- **Stylistic references:** Granola 2026 (бумага + сериф), Blockit (курсивный акцент), Howie (лента работы агента) ⚠️
- **Information density:** средняя: просторные заголовки, плотные списки и ленты шагов ✅
- **Implicit positioning:** премиальный личный сервис, «как свой ассистент», а не корпоративный SaaS ✅

### 1.2 Brand voice / Atmosphere

Selfvoy верит, что человеку не нужен ещё один «умный» интерфейс — ему нужен
доверенный представитель. Поэтому поверхность тихая и бумажная, как письмо от
хорошего секретаря, а единственная яркость — цвет сторон: вы и тот, с кем вы
договариваетесь. Агент не светится и не пульсирует; он показывает работу
строками: «проверил», «предложил», «договорились». Последнее слово всегда
остаётся за человеком, и кнопка подтверждения — самый заметный элемент экрана.

### 1.3 The "ONE brand thing"

- **Что:** «Точка встречи» — два круга, ультрамарин `{colors.voy}` (#2F3BFF) и коралл `{colors.peer}` (#B83A24), пересекаются; пересечение — чернила `{colors.ink}` (#191712).
- **Почему:** это буквально продукт — две стороны находят общее время; ни у одного конкурента нет визуального языка «агент ↔ агент».
- **Как сдержан остальной UI:** всё прочее — бумага, чернила и линии `{colors.line}` (#E0D9CB); никаких градиентов и свечения.
- **Где есть / где нет:** знак, экран переговоров (дорожка раундов), итог встречи, загрузка, launch-ролик; **нет** в списках задач, настройках, формах.

### 2.2 Typography

Дисплей — **Literata** (OFL, TypeTogether для Google), только регуляр 400 + курсив;
выбран вместо Instrument Serif, у которого нет кириллицы. Интерфейс — **Inter**;
время, раунды, коды — **JetBrains Mono** с `tabular-nums`. Все три встроены
локально (`preview/fonts/`, latin + cyrillic). Фолбэки: Georgia / system-ui /
ui-monospace ✅.

| Token | Size | Weight | Line-height | Use |
|---|---|---|---|---|
| `display` | 64px (телефон 44px) | 400 | 1.02 | приветствие, лендинг, итог встречи |
| `title` | 36px (телефон 30px) | 400 | 1.1 | заголовок экрана |
| `heading` | 17px | 600 | 1.35 | заголовок карточки |
| `body` | 15px | 400 | 1.5 | текст, сообщения |
| `label` | 12px | 600 | — | метки секций, ПРОПИСНЫЕ, разрядка 0.06em |
| `mono` | 13px | 500 | — | 14:30, «Раунд 2/5», коды 2FA |

Жест бренда — **одно слово курсивом** в серифном заголовке («Доброе утро, *Алекс*»,
«Договорились *в четверг*»). Не больше одного курсива на заголовок.

### 2.3 Spacing

База 4px; шкала 4 / 8 / 12 / 16 / 20 / 24 / 32 / 48 / 64 / 96. Поля экрана:
20px телефон, 32px десктоп; между секциями 32–48px ✅.

### 2.4 Radii

Три уровня, не смешивать: `{rounded.control}` (10px) — поля и сегменты,
`{rounded.card}` (16px) — карточки и сообщения, `{rounded.sheet}` (24px) — листы
и модалки; `{rounded.pill}` — только кнопки, чипы и аватары ✅.

### 2.5 Elevation system

| Level | Name | Treatment | Use |
|---|---|---|---|
| 0 | плоскость | `paper`, без тени | фон |
| 1 | лист | `card` + 1px `line` | карточки, сообщения, поля |
| 2 | парящий | `card` + `{shadows.float}` | панель вкладок, лист, тост, меню |

Глубина — тоном и линией, тень только у парящего. Декоративной глубины нет:
ни пятен, ни градиентов, ни стекла ✅.

### 2.6 Borders

1px `{colors.line}` (#E0D9CB); при наведении `{colors.line-strong}` (#C9C0AE).
Фокус — 2px `voy` + `{shadows.focus}`. Ваши реплики в переговорах — 2px левая
черта `voy`, реплики собеседника — `peer` ✅.

### 2.7 Accessibility quick-check

Из `design-a11y.md`: все 14 пар проходят AA для обычного текста; ink on paper
15.61:1 AAA, white on voy (CTA) 6.58:1 AA, voy on paper 5.74:1 AA, peer on paper
4.99:1 AA, ink-3 on paper 4.83:1 AA, тёмная тема — от 6.38:1 до 15.89:1.
Цвет сторон всегда дублируется текстом («Вы», «Дима») и формой.

## 3. Components Inventory

### 3.1 Generic components

#### button-primary
- Варианты: основной `voy`; «подтвердить» — тот же `voy` с иконкой галочки.
- Размеры: 44px (по умолчанию), 36px (компактный); ширина по содержимому, на телефоне в листах — во всю ширину.
- Состояния: hover `voy-hover`, нажатие scale 0.98, фокус — кольцо, busy — точка встречи вместо иконки, disabled — 40%.
- Отступы/радиус: 12px 20px, `pill`.
- Один основной на экран ✅.

#### button-secondary
- Варианты: обводка (`card` + 1px `line`), тихая (без фона), опасная (текст `danger`).
- Размеры: 44 / 36px.
- Состояния: hover — `line-strong`, нажатие — `sunken`.
- Отступы/радиус: 12px 20px, `pill`.
- Для «Изменить», «Отклонить», «Позже» ✅.

#### input
- Варианты: поле, многострочное, поиск (иконка слева), композер (`sunken`, без рамки).
- Размеры: 44px; композер 52px.
- Состояния: фокус — рамка `voy` + кольцо, ошибка — рамка `danger` + текст под полем.
- Отступы/радиус: 12px 14px, `control`.
- Подпись — над полем, `label`-стиль не используется ✅.

#### card
- Варианты: обычная, «ждёт решения» (2px верхняя черта `warning`), «итог» (фон `agreed-soft`).
- Размеры: по содержимому.
- Состояния: hover в списках — `line-strong`.
- Отступы/радиус: 20px, `card`.
- Списки внутри карточки разделяются 1px `line`, без отдельных рамок ✅.

#### chip
- Варианты: подсказка, фильтр (выбран — `ink` фон, `paper` текст), человек (аватар + имя).
- Размеры: 32px.
- Состояния: выбран, hover — `line-strong`.
- Отступы/радиус: 6px 12px, `pill`.
- Текст в одну строку, длинное — многоточие ✅.

#### envoy-message
- Варианты: человек (справа, `ink` фон, `paper` текст), посланник Selfvoy (слева, `card`), шаг работы (строка без пузыря: иконка-статус + текст `ink-2`).
- Размеры: максимум 72ch.
- Состояния: «думает» — три точки, которые сходятся в одну.
- Отступы/радиус: 14px 16px, `card`, угол к автору 6px.
- Время — `mono` `ink-3` ✅.

### 3.2 Signature components

- **Знак «Точка встречи».** Два круга r=1, центры на расстоянии 1.2r; левый `voy`, правый `peer`, пересечение `ink`. Используется как логотип, индикатор загрузки (круги расходятся и сходятся) и маркер договорённости.
- **Дорожка раундов.** Горизонтальная шкала из 5 делений (лимит переговоров). Синяя точка слева и коралловая справа с каждым раундом сдвигаются к центру; на договорённости — пересекаются в точке встречи. Под шкалой — лента реплик двух посланников с цветной чертой стороны. После 5-го раунда без итога — эскалация человеку.
- **Карточка договорённости.** Серифный дисплей «*Четверг*, 14:30», место, длительность, кто участвует (два аватара внахлёст); одна кнопка «Подтвердить и забронировать».

## 4. Layout & Composition

### 4.1 Grid & containers

Десктоп: сайдбар 248px + контент до 760px (лента) / 1080px (переговоры —
две колонки 1fr 360px). Телефон: одна колонка, поля 20px, панель вкладок
внизу (парящая, 64px). Иерархия — размером и шрифтом (сериф/гротеск), не цветом ✅.

### 4.2 Composition patterns

- **Шапка-письмо:** дата `label` → серифный заголовок с курсивом → строка-подзаголовок.
- **Лента работы:** вертикальная лента шагов посланника со статусами (проверил / предложил / ждёт / договорились).
- **Сплит переговоров:** слева дорожка и лента, справа карточка договорённости (на телефоне — карточка ниже).
- **Неделя:** 7 дней строкой, сегодня — `ink` круг.

### 4.3 Responsive behavior

| Breakpoint | Behavior |
|---|---|
| ≥ 1000px | сайдбар с подписями, переговоры в две колонки |
| 640–999px | рельс 72px из иконок, одна колонка |
| < 640px | панель вкладок внизу, заголовки `display` 44px / `title` 30px |

Цели касания ≥ 44px ✅.

### 4.4 Image behavior

Фото нет. Аватары — круг с инициалами на тёплых тонах (6 оттенков, выбор по
имени). Иконки — Lucide, обводка 1.75px, 20px ✅.

## 6. Do's and Don'ts

### Do
- Держите `{colors.voy}` (#2F3BFF) за «вами» и действием: CTA, фокус, ваш посланник.
- Используйте `{colors.peer}` (#B83A24) только для второй стороны переговоров.
- Ставьте одно слово курсивом Literata в главном заголовке экрана.
- Пишите время и раунды `mono` с `tabular-nums`: 14:30, 2/5.
- Показывайте работу посланника строками со статусом, а не спиннером.

### Don't
- Не возвращайте стекло, свечение, градиенты и фиолетовый — это «вид AI», от которого уходим.
- Не красьте декоративные элементы в `voy`/`peer`: цвет сторон несёт смысл.
- Не используйте сериф мельче 24px и не делайте его жирным.
- Не ставьте два основных `button-primary` на один экран.
- Не смешивайте радиусы: поле — 10px, карточка — 16px, кнопка — пилюля.
