# Brand

## Name and what we do
**Selfvoy** (self + envoy) — личный ИИ-посланник. Договаривается с посланниками
других людей о времени и месте встречи, ставит задачи и напоминания, готовит
письма. Опасные действия — только после подтверждения человека.

## Audience
Занятые люди, у которых календарь забит, а договариваться о встречах некогда:
основатели, менеджеры, фрилансеры. Пишут по-русски, ценят время и приватность.

## What we promote (with the real link)
Приложение Selfvoy: веб, Windows (.exe), Android (.apk), iOS, Qt-desktop.
Ссылки на сборки — GitHub Actions (артефакты `aura-desktop-windows`, `aura-android-debug`);
публичного сайта пока нет — ASK ME.

calm · premium · warm
