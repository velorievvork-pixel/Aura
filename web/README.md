# Aura — веб-клиент

Фронтенд для Aura, сети ИИ-агентов: у каждого человека есть своя Аура, и Ауры сами договариваются между собой.
Вы говорите «Хочу встретиться с Димой в эти выходные и обсудить стартап», ваша Аура связывается с Аурой
Димы, находит общее свободное время и кафе на полпути, где подходит питание обоих, а потом просит вас подтвердить бронь.

Один код на React 19 + TypeScript + Vite работает на всех платформах:

| Платформа | Оболочка | Папка |
|---|---|---|
| iOS | Capacitor 8 (WKWebView, CocoaPods) | `ios/` |
| Android | Capacitor 8 (WebView, Gradle) | `android/` |
| macOS, Windows, Linux | Electron | `electron/` |
| Браузер | — | `dist/` |

Стили лежат в `src/styles/global.css`. На телефонах раскладка на всю ширину экрана, с нижней панелью вкладок
и отступами под вырез и индикатор «домой». На десктопе свой стеклянный заголовок окна поверх родных кнопок.
Шрифт Manrope встроен в приложение, поэтому интерфейс работает без сети.

## Запуск и сборка

```bash
cd aura
npm install
npm run dev            # браузер, http://localhost:5173
npm test               # vitest: движок переговоров и разбор команд

npm run ios            # сборка + cap sync + открыть Xcode (нужен Mac, Xcode, CocoaPods)
npm run android        # сборка + cap sync + открыть Android Studio (JDK 21, Android SDK 36)
npm run desktop        # сборка + окно Electron
npm run desktop:dev    # Electron поверх dev-сервера Vite с горячей перезагрузкой

npm run dist:mac       # .dmg и .zip  (на macOS)
npm run dist:win       # установщик .exe (на Windows)
npm run dist:linux     # .AppImage и .deb
npm run icons          # перегенерировать иконки и заставки всех платформ из scripts/make-icons.mjs
```

После любых изменений в `src/` перед запуском на телефоне выполняйте `npm run cap:sync`: эта команда копирует
свежий `dist/` в нативные проекты.

## Сборки в CI

`.github/workflows/aura-apps.yml` запускается при каждом изменении в `aura/`. Сначала идут тесты и веб-сборка,
затем собираются:

- Android: debug APK, ставится на телефон напрямую;
- iOS: сборка для симулятора, без подписи;
- десктоп: DMG для macOS, EXE для Windows, AppImage и deb для Linux, пока без подписи.

Готовые файлы лежат в разделе **Artifacts** у каждого запуска.

## Что нужно для публикации

| Куда | Что нужно |
|---|---|
| App Store | Apple Developer Program ($99 в год), сертификат и provisioning profile. Сборка `xcodebuild archive` или Xcode → Archive, затем загрузка в App Store Connect / TestFlight |
| Google Play | аккаунт разработчика ($25 один раз), keystore для подписи. Сборка `./gradlew bundleRelease` (AAB) |
| macOS вне App Store | сертификат Developer ID и нотаризация. В electron-builder это переменные `CSC_LINK`, `CSC_KEY_PASSWORD`, `APPLE_ID`, `APPLE_APP_SPECIFIC_PASSWORD`, `APPLE_TEAM_ID` |
| Windows | сертификат подписи кода (`CSC_LINK`, `CSC_KEY_PASSWORD`), иначе SmartScreen будет предупреждать при установке |

Идентификатор приложения на всех платформах: `app.aura.network`. Он задан в `capacitor.config.ts` и в `package.json` → `build.appId`.

## Нативные возможности

- **Голос.** На iOS и Android работает системное распознавание речи (`@capacitor-community/speech-recognition`),
  разрешения на микрофон и распознавание прописаны в `Info.plist` и манифесте. В браузере используется Web Speech API.
  В Electron распознавателя нет, поэтому кнопка микрофона там отключена.
- Строка состояния, заставка, клавиатура (`adjustResize`) и тактильный отклик при отправке команды и подтверждении брони.
- **Кнопка «Назад» на Android** возвращает на предыдущий экран, а с главного экрана сворачивает приложение.
- **Десктоп.** Окно без системного заголовка: на macOS кнопки окна встроены в боковую панель, на Windows и Linux
  они нарисованы поверх приложения. Внешние ссылки открываются в браузере, вторая копия приложения не запускается.

## Экраны

| Маршрут | Экран |
|---|---|
| `#/login` | Вход. «Демо-вход» и «Продолжить с Google» сразу открывают демо-аккаунт |
| `#/signup` | Регистрация: имя, email, пароль, часовой пояс, «с чем помогать». После неё открывается чат |
| `#/` | Главная: приветствие по времени суток, командная строка (текст или голос через Web Speech API), быстрые действия, ближайшие задачи, идущие переговоры, лента действий Ауры |
| `#/aura` | Чат с Аурой: кнопки ответа («Да, утвердить / Без ограничений / Изменить условия»), индикатор «Аура думает», панель «Память» |
| `#/negotiations`, `#/negotiations/:id` | Переговоры в реальном времени: две карточки агентов, раунды по шагам, итог (день, время, место, стоимость, расстояния), «Подтвердить и забронировать» или «Остановить». Если договориться не вышло, можно повторить с другими условиями |
| `#/tasks` | Неделя, задачи на выбранный день, «Дальше», «Выполнено», подсказка «до следующего события», добавление задачи |
| `#/contacts` | Поиск, фильтры, профиль: общие встречи, разрешения, питание; «Начать переговоры» (тема, период, бюджет); приглашение тех, у кого нет Ауры |
| `#/settings` | Профиль и что Ауре разрешено делать |

## Как устроено

- `src/lib/negotiation.ts` — движок переговоров, чистая функция `negotiate(request, me, them, venues, now)`.
  Раунды такие: моя Аура предлагает первое своё свободное окно, Аура собеседника проверяет календарь (каждая
  сторона сообщает только «свободен или занят» на предложенное время), при конфликте предлагает общее окно,
  затем выбирает место: подходит по питанию обоих, открыто на всё время встречи, укладывается в бюджет;
  из подходящих берётся то, где более длинная из двух дорог короче всего. Если какой-то шаг невозможен,
  переговоры останавливаются, и пользователь видит причину.
- `src/lib/intent.ts` — разбор русских команд: встреча (с кем, когда, бюджет, длительность, тема), напоминание, расписание, письмо.
- `src/state/store.tsx` — состояние приложения (useReducer и контекст, сохраняется в localStorage). Здесь же
  переговоры проигрываются по шагам и результат отправляется в чат.
- `src/platform/` — определение платформы (`data-platform` на `<html>`), настройка нативных плагинов, кнопка «Назад» на Android.
- `src/data/mock.ts` — демо-данные: контакты с календарями и питанием, заведения с координатами и средним чеком.

Бэкенда пока нет. Чтобы подключить настоящий протокол «агент–агент», нужно заменить вызов `negotiate()` в
`startNegotiation` на запрос к серверу, который возвращает те же `steps` и `outcome`. Остальной UI менять не придётся.
