# Aura — личный ИИ-агент (Telegram + Android, один бэкенд)

Aura запоминает всё о пользователе (факты, предпочтения, расписание, контакты), общается,
сама ведёт задачи и напоминания по естественной речи, понимает голос, договаривается
с агентами других людей о встречах и со временем знает пользователя лучше всех.

Два окна к одному агенту:
- **Telegram-бот** (aiogram 3);
- **Android APK** (Kotlin + Jetpack Compose, `bot/android`) через HTTP/WS API (FastAPI).

Оба ходят в **один процесс** `python -m aura_bot`: одна БД, одна память, одни задачи.

| # | Этап | Статус |
|---|---|---|
| 1 | БД + онбординг-анкета в TG | ✅ |
| 2 | Чат + долгая память | ✅ |
| 3 | Задачи + пуши (TG, FCM, WebSocket) | ✅ |
| 4 | Голос (STT, озвучка) | ✅ |
| 5 | HTTP API + Android-клиент + сборка APK в Actions | ✅ |
| 6 | Подписка: лимит в день, премиум за Stars / TON | ✅ |
| + | Переговоры агентов о встрече (5 раундов → эскалация) | ✅ |

## Быстрый старт (сервер)

```bash
cd bot
python3.11 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # BOT_TOKEN от @BotFather, OPENAI_API_KEY; остальное — по желанию
python -m aura_bot        # бот (long polling) + API на :8080 + планировщик; база aura.db создастся сама
pytest                    # 108 тестов, без сети и без ключей
```

Docker: `docker build -t aura-bot bot && docker run --env-file bot/.env -p 8080:8080 -v aura-data:/data aura-bot`.

Без `BOT_TOKEN` запускается только API (для APK), без `OPENAI_API_KEY` агент честно отвечает,
что LLM не настроена. Все ключи — только в окружении (`.env`, шаблон `.env.example`).

## Android APK

- **Готовый APK**: GitHub → Actions → «Build Aura Agent APK» → Artifacts → `aura-agent-android-debug`.
- Локально: открыть `bot/android` в Android Studio или `gradle wrapper --gradle-version 8.7 && ./gradlew :app:assembleDebug`
  → `app/build/outputs/apk/debug/app-debug.apk`.
- Адрес сервера вводится на экране входа (по умолчанию `http://10.0.2.2:8080` — компьютер из эмулятора);
  для сборки с вашим адресом задайте секрет репозитория `AURA_API_URL`. http разрешён только в debug-сборке.
- **Пуши FCM** (необязательно): в Firebase создайте Android-приложение `ai.aura.agent`; на сервере укажите
  `FCM_CREDENTIALS_FILE` (JSON сервисного аккаунта), в секретах репозитория — `AURA_FCM_API_KEY`,
  `AURA_FCM_APP_ID`, `AURA_FCM_PROJECT_ID`, `AURA_FCM_SENDER_ID`. Без них напоминания приходят в Telegram
  и в открытое приложение (WebSocket).
- Общий аккаунт: в боте `/link` → код → в приложении «Ещё → Привязать». Аккаунты сливаются,
  память, задачи и подписка становятся общими.

## Telegram-команды

`/start` анкета · `/tasks` задачи · `/memory` память · `/forget [слово]` забыть · `/meet @user тема [мин]` встреча ·
`/settings` пояс, голосовые ответы, привязка · `/stats` · `/premium` · `/link` · `/paysupport` · `/cancel`.
Плюс свободный текст и голосовые: «напомни завтра в 15:00 позвонить маме», «договорись с @oleg о кофе».

## Как устроено

| Модуль | Что делает |
|---|---|
| `models.py`, `db.py` | SQLAlchemy 2 (async), SQLite → PostgreSQL сменой `DATABASE_URL`; новые колонки добавляются при старте |
| `onboarding.py` | анкета: валидация + `profile_prompt()` («аллергия: арахис — НИКОГДА не советуй…») |
| `agent.py` | ядро для TG и API: контекст (персона, анкета, память, время, история) → JSON `{reply, task, meeting}` |
| `memory.py` | после ответа LLM извлекает `{kind, text}`; сервер проверяет схему, дубли, секреты |
| `tasks.py`, `scheduler.py` | `{datetime, text, repeat}` от LLM проверяется сервером; APScheduler шлёт напоминания |
| `notifier.py` | одно событие — в Telegram, FCM (HTTP v1) и WebSocket |
| `speech.py` | STT (Whisper-совместимый `/audio/transcriptions`), TTS для голосовых ответов в TG |
| `negotiation.py` | агенты по очереди предлагают время; сервер проверяет занятость и часы; 5 раундов → эскалация |
| `billing.py` | дневной лимит (общий для TG и APK), премиум: Stars (XTR) и TON (toncenter), идемпотентно |
| `accounts.py`, `api.py` | email + пароль (Argon2id), токены (в БД — SHA-256), привязка TG, REST + `/api/ws` |

### Безопасность — правила продукта
- Без телефона и SMS: в TG аккаунт = TG ID, в APK — email + пароль (Argon2id, минимум 8 символов, буквы и цифры),
  ограничение попыток входа.
- **LLM — не источник истины**: всё её JSON (задачи, память, ходы переговоров) проверяет сервер. Он отсекает прошлое время,
  неизвестные типы, чужие и занятые слоты, ночные часы, секреты в памяти.
- **Опасные действия — только через подтверждение**: «стереть всю память», «удалить все задачи» — отдельной
  кнопкой или диалогом; встреча попадает в календари только после «да» **обоих** людей.
- Кнопки и id из клиента не доверяются: чужие задачи, записи памяти и переговоры недоступны.
- Оплата: payload счёта Stars привязан к пользователю и цене; повторное уведомление о платеже не продлевает дважды.

### Деньги
Бесплатно — `FREE_MESSAGES_PER_DAY` сообщений в день (по поясу пользователя). Премиум — 399 ₽/мес:
`PREMIUM_PRICE_STARS` звёзд Telegram (`/premium`) или `PREMIUM_PRICE_TON` TON на `TON_WALLET` с уникальным
комментарием. Комиссий сторов нет: в APK оплата открывается в Telegram или в TON-кошельке.

## Ограничения
- Незаконченная анкета в TG хранится в памяти процесса; один процесс на базу (планировщик внутри процесса).
- Каждое сообщение — 2 запроса к LLM (ответ + память); в контексте последние 80 фактов (RAG — позже).
- Задача без длительности считается часом занятости при переговорах.
- Stars — разовая покупка на `PREMIUM_DAYS` дней (не автопродление); возвраты — вручную через /paysupport.
- Подтверждение email не делается (нет почтового сервиса); при переезде на PostgreSQL добавить Alembic.
